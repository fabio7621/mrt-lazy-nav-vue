# 捷運懶人導航

> 不用看懂捷運路網圖，只要選好起點和終點，一步一步照著做就能到。

一個給「不熟台北捷運」的人用的網頁導航。輸入起訖站後，系統自動算出最少轉乘的路線，導航時畫面上一次只告訴你**現在該做的那一件事**。

## 發想

### 起點：看不懂地圖的焦慮

第一次到台北、或是要去沒去過的站時，常常要站在路網圖前面找半天：我在哪條線？要往哪個方向？在哪一站換車？換車後又是哪個方向？

這些資訊其實都在地圖上，但**地圖一次給了全部的資訊，使用者卻只需要其中一小段**。

### 現有工具的空隙

台北捷運官方 App「台北捷運Go」和 Google 地圖都有路線規劃，功能很完整，但結果通常是一整串路線清單或一張地圖。在月台上趕車、在車廂裡被人擠的時候，還是要自己從清單裡找出「我現在走到哪一步」。

### 這個專案的想法

把導航從「看懂整張地圖」改成「現在只做一件事」：

```
🚉 在龍山寺搭板南線，往南港展覽館
🚃 坐 6 站，在忠孝復興下車
🔁 轉文湖線，往南港展覽館
🚃 坐 5 站，在劍南路下車
✅ 抵達
```

就像有人站在旁邊提醒你：「好，上車了嗎？那接下來坐 6 站。」做完一步按一下，畫面才換下一步。

### 設計原則

| 原則 | 做法 |
|---|---|
| **一次只看一件事** | 導航畫面只有一張大卡片，字級放大到在晃動的車廂裡也看得清楚 |
| **用顏色認路** | 卡片底色直接換成該路線的顏色，跟站內指標的顏色一致，不用讀字也能對上 |
| **單手操作** | 主要按鈕固定在畫面底部，拇指按得到的位置 |
| **少轉一次車比少坐一站重要** | 路線演算法把轉乘算成額外成本，避開「站數一樣但要多換一次車」的路線 |
| **可以後悔** | 坐過站或按錯，按「上一步」就能退回 |

## 功能

### 查詢路線

- **站名自動完成**：輸入部分站名就會列出候選站，並標示每站的路線代碼徽章（例如 `BL11` `G12`）
- **多種輸入方式**：支援完整站名、多打一個「站」字、「臺／台」混用，也可以直接輸入車站代碼（`BL11`、`r10`）
- **鍵盤操作**：上下鍵選擇、Enter 確認；注音選字時按 Enter 不會誤選
- **起訖站互換**：一鍵交換起點與終點，查回程很方便
- **路線預覽**：開始前先看總站數、轉乘次數，以及每一段要搭哪條線、往哪個方向、坐幾站
- **最近查過**：保留最近 4 筆路線，點一下就能再查

### 逐步導航

- **四種步驟**：進站搭車、乘車中、轉乘、抵達，每種步驟有各自的版面和提示文字
- **方向提示**：明確顯示「往 ○○ 方向」，對應月台上的指標
- **沿途站列表**：乘車步驟會列出經過的每一站，標示「上車／下一站／下車」；站數太多時會把中間折疊，需要時再展開
- **下車提醒文字**：提示「聽到『○○』到站後，下一站就要下車」
- **接下來預告**：卡片下方預告下一步要做什麼，轉乘前可以先有心理準備
- **進度條**：用路線顏色分段顯示目前走到第幾步
- **螢幕保持開啟**：導航中盡量讓手機螢幕不自動熄滅（需瀏覽器支援）
- **記住進度**：導航途中關掉或重新整理頁面，再打開會回到原本那一步

### 介面

- RWD，以手機單手使用為主，桌機也能正常瀏覽
- 自動跟隨系統的淺色／深色模式
- 鍵盤可完整操作，有清楚的焦點樣式
- 尊重系統的「減少動態效果」設定

## 路線怎麼算

把捷運網路看成一張圖，用 **Dijkstra 演算法**找成本最低的路線：

- 每坐一站成本 **2**（約 2 分鐘）
- 每轉乘一次成本 **7**（約 7 分鐘，包含走轉乘通道與候車）

節點不是單純的「車站」，而是「車站 + 正在搭的列車」，例如 `西門｜板南線`。在同一站換到另一條線，就是一條成本為 7 的邊。這樣演算法才分得出「坐 10 站不轉車」和「坐 9 站轉 1 次」哪個比較好。

有分支的路線（中和新蘆線、新北投、小碧潭）會拆成多種實際行駛的列車，所以能正確提示「迴龍往蘆洲要在大橋頭換車」。

> 成本是估算值，不是官方行駛時間，現場請以站內指標與廣播為準。

## 啟動

需要 Node.js 18 以上。

```bash
npm install
npm run dev            # 開發模式
npm run dev -- --host  # 同一個 Wi-Fi 下用手機開啟
npm run build          # 產生 dist/，可直接部署到 GitHub Pages
npm run preview        # 預覽 build 結果
```

## 專案結構

```
src/
├─ main.js
├─ App.vue                    查詢頁與畫面切換
├─ assets/main.css            顏色、字體等全域設定
├─ data/metro.js              路網資料：路線顏色、各列車停靠站
├─ utils/
│  ├─ station.js              站名正規化、搜尋、代碼查詢
│  ├─ route.js                找路演算法、拆解成導航步驟
│  └─ storage.js              本機儲存
└─ components/
   ├─ StationInput.vue        站名輸入與自動完成
   ├─ RoutePreview.vue        路線摘要
   ├─ NavigationView.vue      導航頁
   ├─ StepCard.vue            單一步驟卡片
   └─ LineCode.vue            車站代碼徽章
```
